# Retail Inventory Web App

This is a standalone HTML application. Its displayed product, stock, revenue, and rating data is saved in `data.js`, so it does not need a server or database connection.

## Start on macOS

1. Double-click `index.html`.
2. It will open in your default web browser.

The main Python desktop app and its normalized SQLite database remain available in the parent `RetailDatabaseApp` folder.
